# Triage Labels

As skills falam em cinco papéis canônicos de triage. Este arquivo mapeia esses papéis para as strings de label usadas de fato no issue tracker deste repositório.

| Label em mattpocock/skills | Label no nosso tracker | Significado                                     |
| -------------------------- | ---------------------- | ----------------------------------------------- |
| `needs-triage`             | `needs-triage`         | Mantenedor precisa avaliar esta issue           |
| `needs-info`               | `needs-info`           | Aguardando mais informação do reporter          |
| `ready-for-agent`          | `ready-for-agent`      | Totalmente especificada, pronta para um agente AFK |
| `ready-for-human`          | `ready-for-human`      | Requer implementação humana                     |
| `wontfix`                  | `wontfix`              | Não será tratada                                |

Quando uma skill mencionar um papel (ex.: "aplique o label de triage pronto-para-agente"), use a string de label correspondente desta tabela.

Edite a coluna da direita para refletir o vocabulário que você realmente usa.
